# PRD — Thief Strategy

Status: Thief strategy scope confirmed; exact strategy design remains open.

Evasion, survival, route selection, Thief-local strategy, and Thief-local verbal
behavior are in scope. Appendix E rule 25 recommends keeping movement decisions
algorithmic and using an LLM for text and behavioral-profile generation. It is a
recommendation without a mandatory sanction, not a prohibition. Appendix F values and
statuses are directly confirmed in `AF-013` through `AF-019`. No particular algorithm,
weight, interface, truth/bluff rule, JSON schema, or MCP message is confirmed here.
