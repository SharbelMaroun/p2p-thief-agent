# ADR-0007: LLM Movement Policy

Status: Proposed

## Evidence

Official project book v3.0.0 Appendix E rule 25, PDF p.146 / printed p.130,
recommends algorithmic movement and LLM use for text or behavioral profiles. It is a
recommendation without a mandatory sanction (`AE-025`), not a prohibition.

## Proposal awaiting acceptance

Keep deterministic algorithmic movement as the local default without turning rule 25
into a mandatory contract restriction. No movement algorithm, LLM provider behavior,
or cross-team exception process is decided here.
