# ADR-0008: Simulator Reuse and License

Status: Pending

## Evidence

The authority order places the lecturer simulator below the official book and course
templates. The inspected reference is commit
`960499fd5e8777b4929625f5d8fdcf2ab4677b54`; no license, provenance, or lecturer
permission supporting source reuse is recorded here.

## Decision needed

Record ownership, license, permitted reuse, provenance, and clean-room boundaries before
copying source. Until then, no substantial simulator source or simulator-only behavior
is adopted.
